## 🚀 About GhostOS

GhostOS is a desktop application designed to bring system utilities, file management, command execution and AI-assisted workflows into one unified interface.

The project explores desktop application development, operating system interaction, process management and automation using Electron and Node.js.

## ✨ Key Features

- 🖥️ **System Information:** Access system-related information through a desktop interface.
- 📁 **File Manager:** Navigate commonly used directories such as Desktop, Documents and Downloads.
- 💻 **Ghost Terminal:** Execute supported system commands from the application.
- 🤖 **AI Assistant:** AI-powered interaction for user queries and productivity tasks.
- ⚡ **Application Launcher:** Launch supported Windows applications.
- 🔄 **Automation:** Experimental workflows for automating selected desktop tasks.
- 🎨 **Desktop Interface:** Custom interface built with HTML, CSS and JavaScript.

> Note: Some features are experimental and may require additional configuration.

## ⚙️ Installation

### Prerequisites

- Node.js
- npm
- Git
- Windows (primary development platform)

### Step 1: Clone Repository

```bash
git clone https://github.com/PhantomPrince-tech/GhostOS.git
```

### Step 2: Open Project

```bash
cd GhostOS
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Run Application

```bash
npm start
```

The start command requires a valid start script in package.json.

Some AI functionality may require additional configuration. Never commit API keys or other credentials to the repository.
